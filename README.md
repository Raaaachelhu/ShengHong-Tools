# 宏盛酒庄工作台 · GitHub Pages完整部署包

这是网站部署包，解压后将本目录中的所有文件上传到GitHub仓库根目录，无需npm、安装依赖或构建。

## 上传步骤

1. 解压压缩包。不要直接将ZIP上传到GitHub。
2. 仓库首页 → Add file → Upload files，上传 index.html、README.md 和 .nojekyll（隐藏文件未显示时，前两项也能正常部署）。
3. 确保仓库首页就能看到 index.html，不要把它放到额外的文件夹中。
4. Settings → Pages → Source: Deploy from a branch → Branch: main → / (root) → Save。
5. 等待部署完成，打开GitHub提供的Pages网址。如果之前上传过旧版，覆盖根目录的index.html，然后使用Command+Shift+R或Ctrl+F5刷新。

## 首次使用

网页功能、样式和计算逻辑全部内置在index.html，单个文件即可运行。

网站首次打开为空白业务数据。进入「数据与设置」→「导入历史数据 / 恢复备份」，选择之前单独下载的 Hongsheng_Private_History.json。

该JSON包含36个商品编码与448笔主表历史记录。不要将经营数据JSON或包含经营数据的本地完整版HTML上传到公开仓库。JSON只需在网站内导入一次，不需要在仓库中存放。

## 已包含功能

商品编码自动带出基础信息、采购入库、三局出库、老板自用、三类退回、库存与流水、两类月报、CSV导出、打印、待提货与分批提货、完整JSON备份恢复。

数据保存在当前网址的当前浏览器，保存后即时更新，不自动写回GitHub，不跨设备同步。每天导出备份，换电脑或清理浏览器前先备份。后续恢复请导入最新备份，不要重新导入旧历史数据覆盖新记录。

历史库存及成本暂算，期初、商品规格及退回异常仍需核对；旧表特殊对账价差、收付款、完整损益及自动箱瓶换算尚未接入。

本包是可部署网页，不是之前的含经营数据本地离线包。
