- 快速录单的商品编码改为直接下拉选择，显示「编码 · 名称 · 单位」。采购、三局、老板自用及退回均使用同一商品下拉框。
- 已内置原Excel主表36个编码、448笔记录，日期2026-02-03至2026-10-28，首次打开默认2026年10月，无需手动导入JSON。
- 库存与流水显示历史明细，可清除月份查看全部；月报按月份分三局及老板自用统计，保留退回负向抵减。
- 如果当前浏览器已有新数据，会优先保留。首页「查看 / 载入过往流水」可补入缺失的内置历史，不清空新录入，原始ID相同的记录不会重复导入。

## 数据口径

448笔包含141笔入库、307笔原出库；其中4笔负数出库已转换为退回、2笔零数量保留。13行空白占位未导入。其他附表未作为流水重复导入。期初、包装与退库实物仍待业务核实，成本与库存暂算。修改记录使用作废后重新录入。

## 发布与保存

此版本index.html包含真实历史商品、客户摘要和采购销售价格。上传公开仓库或发布公开Pages后，仓库访问者与网页访问者可以读取这些内置资料。页面没有身份验证。

新录入数据只保存在当前浏览器，不会写回GitHub，不跨设备同步；每天导出完整JSON备份。切换浏览器、设备或清理缓存之前先备份。恢复时选最新备份，避免用旧历史覆盖新增记录。

所有程序、样式和内置历史都在index.html，无需安装、构建、联网加载第三方脚本。
